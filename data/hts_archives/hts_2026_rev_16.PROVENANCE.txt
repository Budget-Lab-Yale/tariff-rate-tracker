hts_2026_rev_16.json.gz in this directory was NOT downloaded from USITC.
Revision 16 was current 2026-08-14..2026-08-23 and was superseded before
its JSON was pulled; hts.usitc.gov/reststop/exportList serves only the
CURRENT release, and the static archive host has 403d since June 2026.

It was derived by scripts/reconstruct_hts_2026_rev_16.py as:

    rev_16 = rev_17 minus headings 9903.03.12, .13, .14, .15, .16

which is revision 17's complete delta per its change record (U.S. note 51
+ those five headings, PP 11046/11047/11048 as amended by PP 11056;
nothing else changed).

The result is verified against a SECOND, INDEPENDENT source -- revision
16's own change record -- which states its delta against revision 15 is
exactly:

    + 9903.45.30, + 9903.45.31   quartz safeguard, U.S. note 41, PP 11051
    ~ 7020.00.6000               unit of quantity, 484(f): No. -> No., m2
    (no deletions)

The script asserts that delta and aborts if it does not hold, so both
change records and the JSON arithmetic must agree. This is a deletion of
five known records, not an interpolation -- unlike revision 14, for which
no JSON is reconstructed and only the Chapter 99 PDF and change record
are preserved.

Records: rev_15 35788, reconstructed rev_16 35790, rev_17 35795.

Re-derive at any time with:
    python scripts/reconstruct_hts_2026_rev_16.py
